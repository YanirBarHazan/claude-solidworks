## 3. Where the cost went (tokens and time)
1. Rebuilding parts that did not need it (fixed by update in place + fingerprint).
2. SolidWorks crashes and modal dialogs (2019 window limit, licence/VPN, our configuration code): each cost a
   diagnosis round. Fixed or logged in version_notes.
3. Stop-and-ask rounds for missing decisions (corner rules, shared items, attach points): use intake.md first.
4. Long log reads: keep to one summary line per item, details in `logs/`.

## 4. Decisions that worked
- Layout in pure Python, CAD placement by computed transforms at the top level; mates only inside sub-assemblies.
- File per exact length for layout-following items, updated in place (files equal within 0.1 mm merged).
- Rod length groups: one length per group (rounded to 10) with the block moving +-10 along the rod.
- Purchased parts measured from their own files (ring centreline, tip offset) and the attach points derived from
  them; the parameter file updated with `[M]` values.
- An error log row per failure, the same turn.

## 5. Decisions that did not work
- Configuration-specific global values for lengths (2019): crashes.
- Hashing a shared module into every fingerprint: one edit reopened everything.
- Interference over the whole 738-component assembly in 2019.
