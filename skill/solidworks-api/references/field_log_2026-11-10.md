## Lessons
1. **Measure, then fix.** The configuration job looked like slow suppression; a per-step timer showed 55 s per tree
   walk repeated 56 times. Suppression itself took 0.6 s.
2. **The first real use of a pipeline finds the bugs.** The P3_T test passed; the first layout change through the
   same pipeline exposed three bugs. Each was caught by a check (bbox / volume, solved vs computed), not by luck.
3. **Mates expose part errors.** A 43 mm pole error made every distance-mate flip 'wrong'; printing each off
   component (position vs computed) made the cause obvious in one run.
4. **Never set a timeout shorter than a measured run on a step that saves only at the end** - save after each unit.
